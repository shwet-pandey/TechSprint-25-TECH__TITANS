Demo Instructions

1. Start the Demo

The system automatically starts in "Normal Cooking" mode. Watch the gas concentration chart update in real-time.

2. Test Scenarios

Click the simulation mode buttons to test different scenarios:

  • Normal Cooking: Safe gas levels (0-50 ppm)
  • Minor Leak: Warning levels (50-200 ppm)
  • Critical Leak: Dangerous levels (200+ ppm) - triggers automatic gas shutoff

3. Watch AI Decisions

The system uses Google Gemini AI to analyze gas patterns and make safety decisions. The decision card shows whether the AI or local logic made the assessment.

4. View History

Check the Alert History table to see past events, decisions, and actions taken by the system.

5. Reset Data

Use the "Reset Demo Data" button to clear all Firebase data and start fresh.
